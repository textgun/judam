# Judam 화면 다시 그리기 — 계획 (2026-11-26)

## 무엇을, 왜
- 요청 — "화이트 계열로 깔끔하게".
- 이 페이지의 일 — 그날 블로그에 올라온 주담통화 후기를 기업별로 훑고, 관심 기업을 검색으로 바로 찾는 것.
- 지금 화면 — 회색 바탕 위 흰 둥근 카드 + 파란 칩. 흔한 카드 모양이라 기업이 늘면 상자만 줄지어 보인다.
  휴대폰 폭에서 요약에 든 긴 주소가 칸 밖으로 넘친다.

## 방향 — 흰 종이 위의 통화 기록부
카드를 걷고, 흰 바탕에 가는 괘선으로 나눈 **기업별 기록 줄**로 바꾼다(전화번호부·통화 메모장처럼).
색은 먹색 하나로 절제하고, 강조는 검색어를 칠하는 **형광펜 노랑** 한 곳에만 쓴다.

### 색 (6개)
| 이름 | 값 | 쓰임 |
|---|---|---|
| 종이 | #ffffff | 페이지 바탕(회색 바탕 없앰) |
| 먹 | #1f2328 | 제목·본문 |
| 연필 | #646b75 | 요약·블로거·종목코드·업종 |
| 괘선 | #e6e8eb | 기업 사이 구분선, 검색창 테두리 |
| 바탕 | #f4f5f7 | 검색창 안, 칩 눌림 |
| 형광펜 | #fff0a8 | 검색어 표시(유일한 색) |

어두운 모드 자동 전환은 없앤다 — 흰 화면 하나로.

### 글꼴
Pretendard 하나(이미 쓰는 글꼴, 사용자의 다른 화면과 같음). 크기 13·14·16·18·30px, 굵기 400·500·700.
숫자는 고정폭 숫자(tabular-nums). CDN 파일은 가변 글꼴 동적 서브셋으로 바꿔 덜 받게 한다(모양은 같음).

### 배치
```
주담통화 데일리                                   (작은 제목)
오늘 올라온 주담통화 후기는 3건, 기업은 2곳입니다.   (큰 문장 — 이 페이지의 얼굴)
11월 26일 목요일 14:14 수집
┌──────────────────────────────────────────┐
│ 🔍 기업명, 종목코드, 키워드로 찾기              │  ← 스크롤해도 위에 붙어 있음
└──────────────────────────────────────────┘
 인텍플러스 1   토모큐브 1   워치리스트 외 1          (흰 칩, 회색 테두리)
────────────────────────────────────────────
 인텍플러스      [인텍플러스] 공유_IR 통화
 064290         요약 두 줄 …
 반도체와반도체장비 투자와 행복한 삶
────────────────────────────────────────────
 토모큐브        [토모큐브] IR 자료 읽어보기 …
 …
────────────────────────────────────────────
 지난 정리   11-26  11-25  …
 안내 문구
```
- 데스크톱 — 왼쪽 열(약 200px)에 기업명·종목코드·업종, 오른쪽에 그 기업 글들. 왼쪽 정렬.
- 휴대폰 — 기업 머리 한 줄 아래에 글이 쌓인다. 긴 주소는 줄바꿈.
- 글 한 건 — 제목(먹, 굵게) → 요약 두 줄(연필) → 블로거 이름. 제목에 마우스를 올리면 밑줄.
- '기타'는 '워치리스트 외'로 이름만 바꿔 맨 아래.

### 원칙
- 상자·그림자·색 바탕 없이 여백과 괘선만으로 나눈다.
- 강조색은 형광펜 하나. 링크도 먹색(밑줄로 구분).
- 키보드 초점은 먹색 테두리로 또렷하게. 움직임 효과는 넣지 않는다.

## 손대는 곳
- `judam.py`의 `CSS`·`render_day()` 마크업·`JS`(선택자만 맞춤). 수집(`collect`)은 건드리지 않는다.

## 확인
- `python judam.py build` → 데스크톱 1280px·휴대폰 390px 캡처, 가로 넘침 없음.
- 검색 — '인텍' 입력 시 1건·형광펜 표시, 없는 말이면 안내 문구, 지우면 원래대로.
- 글 0건인 날 화면.
